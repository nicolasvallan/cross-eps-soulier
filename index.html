Utilisation rapide

  1. Importez ou ajoutez les élèves.
  2. Attribuez les dossards.
  3. Créez les courses et affectez les participants.
  4. Démarrez le chronomètre général.
  5. Validez les passages et les arrivées par numéro de dossard.
  6. Corrigez si nécessaire puis exportez les résultats.

Dossards

Génération A5 : 2 dossards sur une page A4.

1. Sélectionner la course

2. Logos et contenu

Les deux logos restent modifiables et sont mémorisés localement sur l'appareil.

3. Taille des éléments

Chaque élément peut être agrandi ou réduit indépendamment. L'aperçu et le PDF utilisent les mêmes réglages.

4. Format

A5 (148 × 210 mm) — 2 dossards par feuille A4 portrait.

Le bouton PDF ouvre l'impression : choisissez « Enregistrer au format PDF », papier A4 et échelle 100 %.

Sauvegardes

Les données sportives sont synchronisées avec Firestore. Le fichier JSON reste disponible comme sauvegarde de secours. Les fichiers joints aux manifestations restent pour l'instant stockés localement sur l'appareil où ils ont été ajoutés.
